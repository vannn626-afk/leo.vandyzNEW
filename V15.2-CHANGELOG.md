# KING VANDYZ V15.4 — PERSISTENT LOGIN HARDENING

## Fixed
- Persistent Supabase auth session now uses `localStorage` again.
- Existing V15.1 tab session is migrated to persistent storage on first load.
- Closing/reopening Chrome no longer intentionally clears the KING VANDYZ auth session.
- Refresh-token flow remains enabled through `restoreSession()`.

## Preserved
- Drawing theme and all existing themes.
- Tool CMS, Hide/Maintenance settings, tool catalog, Admin/VIP logic.
- Favorites/history/theme localStorage keys.
- Identity-safe profile lookup by JWT `sub`.

## Important
The public Home counter still uses the server-side `public_stats()` RPC. The V15.2 patch does not turn a synthetic `+250` value into a claim of real users.

## V15.4
- Persistent auth storage upgraded to a new localStorage key with V15.2/V15.1 migration.
- Session restore now gets up to 5 seconds and refreshes expired access tokens.
- Temporary network/profile API failures no longer automatically delete a valid stored session.
- Matching profile is still required by JWT `sub`; the identity-safety fix is preserved.
